# Takım logoları

Bu klasöre bir takımın düz PNG amblemini (tercihen şeffaf arka planlı) koyarsan,
uygulama o takım için artık harf rozeti yerine bu görseli kullanır.

Dosya adı kuralı: takım adını küçük harfe çevir, Türkçe karakterleri sadeleştir
(ş→s, ğ→g, ü→u, ö→o, ç→c, ı/İ→i), boşlukları alt çizgiyle değiştir.

Örnekler:
- Fenerbahçe   → fenerbahce.png
- Beşiktaş     → besiktas.png
- Göztepe      → goztepe.png
- Çorum FK     → corum_fk.png
- Gençlerbirliği → genclerbirligi.png

Kocaelispor'un kendi amblemi için bu klasöre bir şey koymana gerek yok —
uygulama onu zaten `kocaelispor_logo.png`'den otomatik kullanıyor.

Bir takım için dosya yoksa, o takım eskisi gibi üç harfli rozetiyle gösterilmeye
devam eder; hiçbir şey bozulmaz.
